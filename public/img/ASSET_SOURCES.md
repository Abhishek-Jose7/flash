# Bit N Build artwork

- `swinging-insomniac.gif` — animated Miles Morales swing scene from [Tenor, shared by Insomniac Games](https://tenor.com/view/web-slinging-miles-morales-peter-parker-spider-man-marvel%27s-spider-man-2-gif-4657263312711368850).
- `miles-action.gif`, `gwen-action.gif`, and the original character cutouts were bundled with the project before this redesign.
- `user-*.png` — artwork supplied by the site owner. `user-maze-cutout.png` and `user-do-over-cutout.png` are transparent-background versions made for this design; the original files are retained.
- The six PNGs used by the app have lossless `.webp` delivery copies. The app references those WebP files; PNG and GIF source files remain in the workspace and are excluded from the Docker image.

Spider-Man and related character artwork belongs to its respective rights holders. This is a fan event interface.
